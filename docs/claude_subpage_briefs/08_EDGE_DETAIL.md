# Claude Brief: Edge Detail

Route:
- `/edge/{id}`

Files:
- `web/templates/edge.html`
- `web/static/style.css`

Goal:
- Turn the edge page into the flagship evidence dossier experience.

Current function to preserve:
- summary
- mechanism
- caveats
- supporting evidence table
- counter-evidence panel
- retraction alert
- audit trail / history
- share PNG link

Design direction:
- this should feel like the core product
- premium research dossier, not a plain detail page
- summary and evidence should both feel first-class

What to improve:
- stronger visual hierarchy in the hero area
- better segmentation of summary, mechanism, caveats, and evidence
- supporting evidence table should be easier to scan
- retraction and counter-evidence states should be especially clear

Acceptance criteria:
- page feels like a premium evidence brief
- high-stakes trust signals are clearer
- table remains readable on desktop and mobile
- no loss of any current evidence functionality
