# Claude Brief: Search

Route:
- `/search`

Files:
- `web/templates/search.html`
- `web/static/style.css`

Goal:
- Make `/search` feel like a real evidence retrieval surface.

Current function to preserve:
- search form
- topics chips
- evidence result cards
- semantic match explanation

Design direction:
- clean, intelligent, retrieval-oriented
- should feel like searching a premium health knowledge base

What to improve:
- search header and query framing
- distinction between topics and evidence results
- stronger result-card composition
- semantic explanation should feel helpful, not technical clutter

Acceptance criteria:
- search feels more useful and more premium
- results are easier to scan
- topics and evidence are more clearly separated
- behavior remains unchanged
