# Claude Brief: About

Route:
- `/about`

Files:
- `web/templates/about.html`
- `web/static/style.css`

Goal:
- Make `/about` feel like a premium methodology and credibility page.

Current function to preserve:
- explains how cards are seeded, verified, tiered, updated, watched for retractions
- shows project stats
- shows cost discipline
- shows what the product will not do

Design direction:
- transparent, rigorous, and beautifully structured
- should feel like a research publication’s methods page
- long-form content should be much easier to scan

What to improve:
- typography rhythm for dense content
- hierarchy between stats, workflow steps, side notes, and caveats
- better treatment of the tier explanation
- acknowledgements and limitations should read as intentional sections

Acceptance criteria:
- page is easier to trust and easier to read
- dense methodology content is visually digestible
- no change to factual content unless formatting requires minor copy polish
