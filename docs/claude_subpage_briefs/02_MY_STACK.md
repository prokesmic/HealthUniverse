# Claude Brief: My Stack

Route:
- `/me`

Files:
- `web/templates/me.html`
- `web/static/style.css`

Goal:
- Make `/me` feel like a premium private workspace, not a plain settings form.

Current function to preserve:
- local-cookie-only profile
- age / sex inputs
- condition selection
- current stack selection
- save / clear actions
- relevant-for-you results

Design direction:
- a high-trust personal health workspace
- clear privacy reassurance
- onboarding should feel warm and guided
- selected conditions / stack items should feel intentional and easy to scan

What to improve:
- form hierarchy
- chip selection clarity
- stronger visual grouping between profile inputs and personalized output
- “Relevant for you” should feel like a personalized dossier, not leftover cards

Acceptance criteria:
- privacy-first tone is clearer
- stack building feels easier and more premium
- relevant results feel personalized and important
- form behavior remains unchanged
