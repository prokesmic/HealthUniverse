Privacy is the headline: your data is encrypted in this browser before it ever leaves your device.

          Sign in first. Always-on needs an account to know where to send the daily briefing.
          1. Back up your data (encrypted)

          Encrypts your labs / wearables / genetics / records / protocols with a passphrase YOU set. The server stores only ciphertext. Restoring on another device just needs the same passphrase.

          2. Opt in to daily compute

          When enabled, we sync a small summary view (anomaly z-scores, watchlist edge IDs, open recommendations, next visit date, recently-flagged lab names) so the server can run the daily check. No raw wearable streams, no raw lab values by default — just derived signals.

          3. Allow push notifications

          Daily notifications land via the Web Push standard. Works on Chrome/Edge/Firefox desktop and on installed PWAs (Add to Home Screen) on iOS & Android. If push isn't available we fall back to email.
